# Root2AI_internship_task

This is my submission to an internship classification task at Root2AI, completed during my Bachelor's degree. I built a text classification model to predict the target category for a blockchain-related dataset.

**Note:** The dataset used for this task is proprietary company data and is not included in this repository due to confidentiality.

## Approach

- Text features were converted into numeric vectors using TF-IDF
- A Random Forest classifier was trained to predict the target category
- The model was evaluated on a held-out test split

See `Aishwarya_Shanbhag_Root2AI_Report.pdf` for the full write-up.
